# Portafolio · Breidy Caicedo

Piezas gráficas y reels que he hecho para las redes de Ingeniería en Energía Inteligente, Ingeniería Bioquímica y Biología de la Universidad Icesi, y para POWEX Energy Meeting.

Página: https://breidycaicedo.github.io/Portafolio-Breidy-Caicedo/

El diseño sigue el Manual de identidad Icesi 2026: Azul Icesi y paleta complementaria, Plus Jakarta Sans, bloques de color, retícula de 16 módulos y cenefa.

Para cambiar o agregar piezas, edita `data.js` y pon la imagen en `img/` con el mismo número.
